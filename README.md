# Student-Essential-Cart-Front-end

A responsive front-end shopping cart for student essentials such as chargers, earphones, pencil boxes and laptop stands. Products are rendered dynamically with jQuery, and users can add items to the cart, increase or decrease quantities, and remove items.

Tech stack: HTML5, CSS3, JavaScript (ES6), jQuery 3.6

Features:

Dynamic product listing
Add to cart, with quantity increment and decrement
Remove items from the cart
Responsive layout for smaller screens

Files: 
HTML: index27.html
CSS: style27.css 
Javascript: style27.js
